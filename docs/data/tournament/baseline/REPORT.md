# Tournament report: baseline

Generated by `scripts/tournament.ts`. Every number below was computed by that run; nothing is estimated by hand. Bots are *proxies* for challenge and diversity: they say what the simulation allows, not whether a person has fun.

## Reproduce

```
npm run test:sim -- --scenario all --seeds 1000 --determinism 12 --name baseline --time-budget 6000
```

| Parameter | Value |
| --- | --- |
| Rules version | 1.0.0 (generator v1) |
| Seeds | 1 – 1000 per scenario (identical for every policy: paired) |
| Difficulty | normal |
| Day cap per run | 60 |
| Workers | 4 child processes |
| Wall time | 2685 s |
| Oracle seeds | 0 per scenario (privileged rollouts) |
| Rescue sample | up to 0 lost runs per scenario and policy |
| Determinism re-runs | 12 seeds per scenario and policy |
| Decision-density sample | 0 seeds per scenario and policy |
| Node | v22.22.0 |

> The oracle (when present) is PRIVILEGED: it plays each candidate to the end on a private copy, so it sees every night's dice. It is an upper bound for regret, never a fair opponent.

> The exploit-seeker and the controls (noop, random) are excluded from the "thoughtful" comparisons.

> Expedition seeds are all generated villages in the range, including ones the offline witnesses could not win; win rates there are over every seed, not only verified ones.

## Definitions

* **Win rate**: share of seeds ending in victory; the bracket is the 95% Wilson interval. **n** is the number of seeds played, the same for every policy.
* **Paired**: every policy plays exactly the same seeds, so differences between policies are not luck of the draw. *aOnly / bOnly* count seeds that only one of the two wins; *p* is the exact two-sided sign test on those.
* **Reach**: peak share of living villagers holding conviction >= 50 in a story the Keeper can tell. **First belief / first law**: median day.
* **Unspent AP**: Influence offered by the game and not used. **Pass days**: share of days with no Influence spent.
* **Decision density**: on sampled planning days, the number of enabled actions whose exact preview changes someone's conviction or the physical world ("consequential"); a day with fewer than three is "thin".
* **Separated**: two policies differ materially when their action mixes are at least 0.25 apart (half L1 distance) or they win different seeds on at least 20% of the seeds.
* **Rescue**: of runs that were lost, the share where some *other* thoughtful policy, taking over with 1 / 2 / 3 planning days left, still wins. High values mean the last turns offered a realistic way out; near zero means the loss was already decided.
* **Regret**: seeds this policy loses although another thoughtful policy (or the oracle, where it ran) wins them.
